# 借票管理与代理池 UI 优化（2026-10-10）

已发布 `2.10.1-borrow-ui-1`，应用于 2026-10-10 14:09:53（Asia/Shanghai）启动。入口为本地 18080 的借票管理和代理池页面。

## 问题分析与调整

| 原有问题 | 调整结果 |
| --- | --- |
| 来源选择没有修改时，保存栏仍悬浮在视口下方，遮挡模型和指纹配置 | 未修改时保存栏恢复正常文档布局；有修改时仅桌面端吸底，手机端保持正常布局 |
| 手机端概览卡片和多行运维导航占用较多首屏空间 | 概览压缩为短行；运维导航单行横向滚动，首次打开、切换路由及缩放窗口时保持当前项可见 |
| 页签与操作按钮外观接近，当前页不够清晰 | 借票页签改为分段导航，明确选中、悬停和键盘焦点状态 |
| 自动轮换开关、间隔和按钮混排；代理地址、指纹、执行时间连成一段 | 分成环境信息、执行状态、自动参数和操作区；开关与数字输入框对齐，长地址与账号名称可换行 |
| 自动轮换未启用时，“下次执行”仍可能显示时间或空占位 | 未启用时明确显示“未启用”，与后台暂停和任务处理中区分 |
| 探测数值输入宽度过大，范围说明与对应输入框距离较远 | 限制表单宽度，单位显示在输入框内，每项下方分别说明范围和默认值 |
| 输入非法数字后仅保存按钮不可用，缺少明确原因 | 输入框红色状态、就地错误文案及辅助技术描述；轮换间隔同样在提交前校验整数范围 |
| 保存、恢复配置和立即切换层级接近，禁用的主按钮仍显得突出 | 可提交的保存按钮突出；未修改或非法输入时使用次要样式；手动操作独立排列，手机端按钮完整占行 |
| 代理池导入区多层卡片与阴影叠加，列表启停状态只是普通文字 | 导入区改为浅背景与细边框，输入框压缩为五行；列表增加状态徽标、悬停反馈、等宽地址和窄屏横滑提示 |
| 深色模式的说明、成功及等待状态偏暗；英文长标签使输入框错位 | 补齐深色文字颜色，调整英文标签，并统一行高、控件高度和间距 |

默认探测并发 3、提前恢复 15 秒、来源轮换间隔 60 秒及其数值范围沿用原功能。来源轮换仍仅操作来源，目标页不提供轮换入口。此前“来源共享业务并发”的旧提示已改成与当前隔离实现一致的描述。
