# Sub2API v2.15.1：VM 正式发布与更新修复

本版将 VM 账号执行链路纳入正式发布，更新源统一为 `caims481266251/sub2api`。普通账号、分组、密钥、计费沿用现有 Sub2API 逻辑。代码基线为纯上游 v2.15.0 加 VM 功能，不包含旧 2.10.x 个人分支的借票定制；依赖该定制的部署应先评估功能差异。

## 后台更新

- `v2.15.0-vm.1` 为预发布，不会被 GitHub `/releases/latest` 返回；本版为正式版，可由该仓库的旧版后台检测。
- 更新器按主程序包名选择附件，避免下载 2FA 或 VM 辅助包；版本比较支持预发布顺序；更新缓存绑定仓库。
- 标准主程序包为 `sub2api_2.15.1_<os>_<arch>.tar.gz`（Windows 为 zip）。2FA 包采用 `sub2api-reauth-2.15.1-linux-<arch>.tar.gz`，避免旧更新器按平台片段误选。
- 主程序更新后需要按后台提示重启。Docker 容器内替换二进制不会改变镜像标签；重建容器应使用 `ghcr.io/caims481266251/sub2api:2.15.1` 并沿用现有数据卷和配置。
- 若旧程序的更新源是官方仓库 `ranxi2001/sub2api`，需先手动切换至本仓库发布的程序或镜像；仅发布新 tag 无法改变旧程序内置地址。

## VM 首次部署边界

后台更新只更新 Sub2API 主程序。VM helper、宿主机 Docker/QEMU、固定内核 payload 和隔离网络仍须按 [部署说明](../deploy/vm-kernel/README.md) 安装。不会由网页更新器自动提权安装宿主组件。

Linux amd64/arm64 辅助包为 `vm-kernel-tools-2.15.1-linux-<arch>.tar.gz`，包含 helper、版本化部署脚本及文档，并附 `.sha256` 校验文件。不含账号凭据、实例磁盘或第三方内核 payload。升级已有 VM 部署时使用配套 helper/脚本，保留配置、持久身份和实例数据。

## 验证范围

更新版本比较、缓存来源、主程序附件选择与安装重启锁有回归测试。VM 已有 GPT/TCG 实测记录见相关验收文档；硬件 KVM、Claude 未完成实测。此前 100 并发测试包含上游错误与数据库连接不足，不能视为持续 100 并发全成功验收。
