# 近期功能整理与发布回归（2026-10-10）

后续 UI 优化版本 `2.10.1-borrow-ui-1` 已上线，详见 [UI 优化验收](ticket-borrowing-ui-20261010.md)。本报告保留 13:47 功能发布时的配置快照；当前开关与预算以管理页面为准。

## 发布范围

本轮将此前完成的代理池、来源借票专用绑定、来源自动轮换及每目标探测策略整理为同一发布版本。使用入口为 **智能运维 → 借票管理**，代理池入口为 **代理管理 → 代理池**。

| 功能 | 当前行为 | 默认值及边界 |
| --- | --- | --- |
| 代理池 | 批量预览、追加／替换、去重、启停；凭据加密保存，管理 API 和审计省略敏感内容 | 保留已有池和池版本 |
| 来源自动绑定 | 对已选来源持久分配独占代理、设备 ID 与固定 TLS 指纹；只影响借票环境 | 开关默认关闭；不改来源日常业务代理 |
| 后台借票 | 来源取票后经过目标两阶段复验，通过才发布路由；关闭页面仍运行 | 保留后台开关、来源／目标请求预算及明确的上游等待 |
| 来源手动轮换 | 支持单个或批量随机切换代理＋指纹；先排空本批在途来源，再原子提交 | 无完整替代方案则保留原绑定；不轮换目标 |
| 来源自动轮换 | 每个来源独立保存自动开关和间隔；历史与任务跨重启保留 | 默认关闭，默认 60 秒，范围 1–86400 整数秒 |
| 尽量避免复用 | 全局未用代理优先；不足时用当前来源未用代理；仍不足时取当前来源最久未用代理 | 池不足时允许其他来源使用过的代理；设备与实际 TLS 配置摘要均检查历史 |
| 每目标探测并发 | 各目标独立限额；并发候选首个成功发布后取消、排空其余候选 | 默认每目标 3，范围 1–32 整数 |
| 提前恢复探测 | 无路由则获取；剩余寿命进入阈值后恢复探测，仍有效路由继续服务 | 默认 15 秒，范围 0–240 整数秒；0 表示到期后恢复 |
| 业务与探测隔离 | 探测不占业务并发槽；连接池与客户端缓存限额也独立 | 多实例通过数据库预约遵守每目标探测上限 |
| 业务出口 | 正常业务使用目标账号普通代理配置，无配置则直连 | 不继承借票路由保存的代理 |
| 借票记录 | 只展示借票、候选、轮换及路由状态；过滤历史业务事件 | 正常业务继续进入原业务日志；路由失效保留路由状态事件 |

代理选择遵守其他账号占用与任务预留约束；同批来源允许满池互换。成功绑定即计为使用，代理和指纹历史不会随七天事件清理而消失。固定的是代理配置及设备／TLS 配置，实际出口 IP 由代理供应商决定。

来源和目标各自的频率预算仍然生效，因此配置并发 3 不保证始终有 3 个请求同时运行。提前 15 秒是恢复探测的阈值，不保证 15 秒内取得新路由。已有有效路由、在途业务流和旧会话不会因探测策略保存或来源轮换而提前撤销。
