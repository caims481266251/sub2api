# Sub2API v2.15.2：VM 2FA 导入提示与部署检查

修复 VM 模式的 2FA 登录成功后，账号导入失败却统一提示“检查加密配置”的问题。

- 账号管理能力接口只返回 VM 是否启用的布尔值，不暴露 helper 路径或密钥。
- 未部署 VM 运行环境时禁用 VM 选项；进入登录步骤前重新检查，避免完成上游登录后才发现环境不可用。
- 批量导入保留结构化错误原因，分别显示 VM 未启用、缺少代理和凭据加密问题。未知错误不输出可能含敏感信息的原始响应。
- 导入失败重试继续复用已取得的登录凭据，不重复发起 2FA 登录。普通账号和原计费流程保持不变。

VM 首次部署仍需要配套 helper、固定内核 payload、QEMU 运行镜像、共享 Unix socket 和协调锁目录。主应用使用 UID 1000 与专用补充组直接运行，避免容器入口降权时丢失补充组导致协调锁不可访问。无 `/dev/kvm` 的机器只能显式配置 TCG，不会将软件模拟报告为硬件 KVM。

发布包含标准主程序、Docker 镜像、Linux amd64/arm64 2FA 运行包与 VM 辅助包。详见 deploy/vm-kernel/README.md。
