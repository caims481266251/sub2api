# GitHub 发布与在线更新

本分支的发布仓库是 `caims481266251/sub2api`，持续发布分支为 `codex/vm-kernel-account-mode`。最近已发布版本为 `2.15.21`；当前开发代码已撤销该版本新增的 Docker OpenAI SSE 保活、读取无进展超时及配套失败收尾改动，恢复为 `v2.15.20` 的对应实现。此撤销尚未发布，不改变已有 `v2.15.21` tag 和安装包。

## 发布方式

在已验证的持续发布分支创建带说明的正式 tag，再原子推送分支与 tag：

```bash
git tag -a v2.15.19 -m "Release v2.15.19" -m "本次更新说明"
git push --atomic origin codex/vm-kernel-account-mode v2.15.19
```

`.github/workflows/release.yml` 接收 `v*` tag，自动构建前端及 Windows AMD64、macOS AMD64/ARM64、Linux AMD64/ARM64 更新包，发布 `checksums.txt`、GitHub Release 和 GHCR 多架构镜像。正式 tag 固定完整发布，不能被仓库的 `SIMPLE_RELEASE` 变量降级为仅镜像模式。手动触发仍可选择 simple release，但该模式不提供系统内在线更新包。

更新包命名必须保持 `sub2api_<版本>_<系统>_<架构>.tar.gz`（Windows 为 `.zip`），校验文件必须保持 `checksums.txt`。仅推送 tag 不代表发布完成，应确认 Release 工作流成功且资源已上传。预发布 tag 不进入稳定版本的 latest 更新通道。

## 系统内更新

后端检查更新和回滚均读取本仓库 Releases；重登录运行时也从同一仓库下载。页面回滚指令和安装脚本使用本仓库，Docker 镜像为 `ghcr.io/caims481266251/sub2api`。

已有安装若仍指向旧仓库，需要先安装一次本分支的正式版本；之后即可从管理页面检查并在线更新。发布构建使用 `BuildType=release`，页面才显示更新操作。在线更新需要能访问 GitHub，并允许服务用户写入应用所在目录。

Docker 部署可通过页面更新当前容器中的二进制；重新创建容器会恢复镜像内版本，因此持久升级还应更新 Compose 镜像 tag 并重新创建应用容器：

```yaml
image: ghcr.io/caims481266251/sub2api:2.15.19
```

```bash
docker compose pull app
docker compose up -d --no-deps app
```

服务名以实际 Compose 文件为准。新仓库的 GHCR 软件包第一次发布后，应确认可匿名拉取；仓库公开不一定意味着软件包自动公开。数据库、账号凭据、`.env`、本地备份和运行数据不属于源码发布内容。

## v2.15.21 更新

Docker OpenAI SSE 保活与读取超时修复

- Docker OpenAI Responses 流式请求在首个事件前和事件之间的静默阶段发送 SSE 注释心跳，复用 `gateway.stream_keepalive_interval`，默认 10 秒，设为 0 可关闭；心跳不计入首字延迟、usage 或成功状态。
- 内核响应体读取接入 `gateway.stream_data_interval_timeout`，默认 180 秒，设为 0 可关闭；只对阻塞的内核响应读取计时，真实字节分片和内核注释算读取进展，下游慢写和事件回调不占用读取超时额度。
- 心跳、响应头回调和业务事件统一由单一写入协程串行处理；客户端取消、写入失败、回调失败和尾部响应头均等待内核执行收尾，释放并发槽位并避免重复终态。
- 读取超时与客户端主动取消保持区分，不自动重放未知执行；Responses 在已提交 SSE 后发送保留原响应 ID、模型和创建时间的 `response.failed`，Chat 与 Messages 使用各自兼容的错误帧，并统一记录运维流失败。
- 保留 Docker 内核正常 EOF、trailer 和 usage 校验合同；不改变闭源内核内部上游连接池行为。

验证：本地 Go 回归 183 个顶层测试、含子测试 429 项通过；相关竞态检测 53 个顶层测试、含子测试 158 项通过。真实本地 Docker 运行服务使用 `gpt-5.6-terra` 做 9 项场景预检和 5 分钟 2→5→10 并发阶梯压力测试，94/94 请求成功，观察到 124 次 SSE 心跳，容器无重启或 OOM，并发租约最终归零。

升级：相较 v2.15.20 无新增数据库迁移。正式 tag 包含五个平台主程序更新包、checksums.txt、amd64/arm64 重登录运行包、Docker host tools 与多架构镜像；主程序与 Docker host tools 保持同版本。
