# Codex 账号托管

用户用自己的 Codex OAuth 账号调用 OpenAI 网关，托管账号只供其本人使用。普通 Key 保持原来的分组调用模式。

同一份 OpenAI 账号可以分别导入后台公共账号和用户托管账号，保存为不同记录，独立配置、调度及计费；导入不会覆盖或自动复制另一边的记录。上游订阅额度仍共享，凭证失效等上游状态可能同时影响两边。用户托管之间仍禁止重复身份，不能通过重复导入占用其他用户的账号。

## 开放功能

数据库迁移 `289_account_hosting.sql`、`290_user_hosting_pools.sql` 和 `291_hosting_public_identity_coexistence.sql` 随服务启动执行。功能初始关闭；管理员进入“托管管理”，设置席位与倍率后开启。默认每用户 1 个席位，托管倍率为 `0.03`，可分别调整用户的席位和倍率，留空表示继承全局设置。简易模式不开放托管。

用户进入“账号托管”，点击“添加 Codex 账号”通过 OAuth 授权或 2FA 登录，点击独立的“导入账号”入口导入包含 refresh_token 的 `auth.json`。导入通过上游刷新确认身份和订阅套餐，首期拒绝免费或无法确认套餐的账号；重授权必须是原账号身份。暂停、掉登录、额度耗尽的账号继续占席位，删除后释放；降低上限保留已有账号并禁止超限新增。

用户创建 Key 时选择“我的托管池”。兜底默认勾选，但不自动选择分组；用户必须自行选择有权限的 OpenAI 余额分组或关闭兜底。后台没有默认兜底设置，已保存的用户选择保持不变。关闭功能后托管调用被拒绝，用户仍可查看账号和历史费用、暂停或删除账号。

## 用户托管池

用户可以创建、命名和重命名自己的私有托管池。添加账号时选池，账号配置中可以移动；每个托管 Key 独立选择一个池及其兜底分组。分池不增加席位，调度不会跨池选账号。默认池保留已有账号和 Key，无需重新授权。

托管池与公共兜底分组独立，只有池所属用户可以查看或修改。删除池要求先移出所有账号并修改关联 Key，默认池不能删除。数据库复合外键保证账号、Key 与池归属一致，粘性会话与最终发送检查也包含池维度。接口省略 `hosting_pool_id` 表示更新时保持原池；显式传 `0` 表示默认池。

## 托管账号配置

用户在托管账号卡片点击“账号配置”，可调整名称、备注、并发、优先级、负载因子、到期时间与到期自动暂停、RPM、模型白名单和映射（含别名模式）、WebSocket 模式与 SSE 加速、自动透传、Compact 与独立映射、namespace 兼容、Codex 客户端限制与指纹、图片工具策略、上游 Request ID Header、Excel/BPS 模型及 403 恢复、调度及额度保护阈值、自定义错误冷却规则，以及自动使用重置卡。添加弹窗沿用后台添加账号的布局、授权方式卡片、Select 和 Toggle 控件，只提供 OAuth 和 2FA 登录。导入账号使用独立入口与导入文案，使用后台 OAuth JSON 导入的粘贴面板或与后台数据导入共用的文件拖拽控件，仅选择托管池，不展示可选账号配置，导入后可在账号编辑中调整。支持完整 auth.json、JSON 数组、每行一个 JSON 对象，以及多个 JSON 文件；每个账号必须含 refresh_token。批量账号使用默认配置与所选托管池，名称自动添加序号；逐个调用现有托管导入接口，由服务端校验归属、身份和席位，每个账号原子保存配置。结果展示逐账号成功与失败，成功项保留并从重试中排除；仅重试失败项，或清空输入继续导入新一批。返回可继续修改配置草稿。重新授权只允许一份原账号凭证，预填原配置并保留原账号席位与托管池。

复用现有 OpenAI 字段、模型/RPM/Request ID 组件及网关逻辑；BPS 遵守平台全局开关，全局关闭时保存其他配置不会覆盖已保存的 BPS 值。BPS 网络策略与 Prism 仅保留在后台，托管页面和用户配置接口均不开放。自动使用重置卡默认关闭，用户明确开启后按 5 小时和 7 天窗口阈值触发，0 表示忽略该窗口；沿用原账号重置卡消费逻辑，不属于托管服务费。临时错误冷却规则沿用现有状态码与关键词匹配，最多 20 条，支持排序。

配置接口严格限制字段并校验归属，只允许修改本人账号的调用偏好；不开放凭证、套餐身份、计费倍率、平台分组与管理员代理凭证。配置以事务更新当前记录，保留刷新后的凭证和服务端额度/自动用卡状态。重新授权保留调用配置，不额外占席位。更新时省略根字段保持原值；`load_factor: 0` 和 `expires_at: 0` 分别清除负载因子和到期时间；credentials/extra 中传 `null` 清除对应偏好，不能写服务端运行状态。

## 2FA 登录与后台查看

2FA 登录复用后台凭证守护已配置的登录服务（邮箱、密码与验证器密钥），配置无效时禁用入口并提示使用 OAuth/auth.json。用户界面展示登录服务主机名；密码与 2FA 密钥仅用于这次登录，不持久化到托管账号，也不加入平台凭证运营或旧凭证守护的重登设置。后台自动重登管理未开放到用户托管功能。

用户登录任务最多同时 1 个，绑定登录用户、重授权账号与目标池；平台登录引擎仍有总任务限制和超时回收。查询只返回任务状态，不返回 token、密码或密钥。取消、查询、完成均校验归属，取消和 30 分钟过期清理临时凭证；保存前通过 OpenAI token 刷新验证账号身份与订阅，复用现有去重、席位锁和加密事务。保存失败保留临时登录结果供重试，不重复登录；保存成功销毁任务，禁止重复创建。

后台“托管管理”与“智能运维”使用相同的可折叠导航，内含“托管账号”“用户设置”“托管配置”三个独立页面。旧 `/admin/hosting` 地址转到账号列表。账号页展示所有用户的托管账号，包括暂停、掉登录及限额状态，显示所属用户、托管池、额度与恢复时间。支持按账号名、用户邮箱/用户名、池名搜索，纯数字搜索按用户 ID 精确匹配，点击所属用户可直接筛选；分页可选择每页 20、50、100 条并跳页，桌面端固定表头与底部分页。用户设置页使用分页用户列表，按需打开独立弹窗修改席位和倍率，也可从账号行直接设置所属用户；留空继承全局值，0 为明确覆盖。托管配置页只包含功能开关与全局默认值。各页只读取自身需要的数据。账号数据使用受限视图，不返回账号 token、密码、Prism 或 BPS 网络配置。

用户托管页与后台托管列表复用后台账号管理的 OpenAI 额度面板：5h/7d 进度条、整数百分比、阈值颜色、各窗口恢复倒计时，以及查询、重置卡次数/到期时间、积分和重置确认。列表通过现有 Codex 窗口解析器读取快照，查询按钮调用现有额度探测服务；不为每个列表账号自动发起上游探测。重置操作使用现有消费和恢复流程，成功后更新当前账号行；消费成功但本地恢复或缓存失败时按原有规则显示部分成功提示。用户操作必须通过账号归属校验，后台托管接口只接受托管账号；凭证、平台网络配置及邀请发信入口均不对用户开放。

## 计费

- 托管费用 = 模型价格与实际用量计算的标准金额 × 托管倍率。例如标准用量 100、倍率 0.03，扣现有 USD 钱包余额 3。
- 标准金额是用量的定价基数，不代表用户的订阅账号支付了这笔金额。托管费用不叠加普通分组倍率、账号倍率和高峰倍率。
- 兜底按实际兜底分组的现有计费规则收费，含该用户的分组专属倍率及适用的高峰规则。Key 额度、余额和消费窗口限制继续生效。
- 无可计费用量的失败不扣费；部分输出中断且上游提供了用量时按实际路径记录。使用现有请求幂等账本防止重复扣费。
- HTTP 请求开始时捕获托管倍率，WebSocket 每轮捕获一次；后续改价不改变正在处理的一轮。用量记录展示托管/兜底来源，托管公式、实扣，兜底实际分组与切换原因；账号托管页面分别统计两类费用。

## 调度与凭证

调用顺序为本人可用托管账号、Key 保存的兜底分组、返回明确错误。私有池的安全重试预算用完后可进入兜底；兜底恢复普通调度规则。无效参数、余额不足、Key 限额和分组权限不通过兜底绕过。已经输出内容的流不会跨账号重放；WebSocket 连接内保持当前账号安全续链，不能安全重放时要求客户端携完整上下文重新连接，新请求优先尝试恢复后的托管池。

账号归属覆盖选号、最终发送校验、粘性会话和响应关联。托管账号不进入公共分组、公共调度缓存或插件账号目录，不执行平台采购账号的利润筛选。席位新增在数据库事务中锁用户行，重复身份跨用户串行检查；删除清除凭证并停止调度，历史账单保留。

access_token、refresh_token、id_token 使用现有凭证加密器持久化。备份数据库时同时备份原加密密钥：配置的 TOTP 加密密钥，或 `DATA_DIR/secrets/credential-operations.key`。密钥缺失时拒绝生成替代密钥解密已有凭证。

## 接口

接口前缀为 `/api/v1`，用户接口使用现有登录鉴权，后台接口使用管理员鉴权。

| 接口 | 用途 |
| --- | --- |
| GET /hosting/status | 开关、当前倍率和本人托管池 |
| POST /hosting/pools | 创建私有托管池 |
| PUT /hosting/pools/:id | 重命名本人托管池 |
| DELETE /hosting/pools/:id | 删除未被账号或 Key 使用的池 |
| GET /hosting | 席位、账号安全视图和费用汇总 |
| POST /hosting/import | 导入 auth.json，可传 replace_id 重授权及 settings 一起保存 |
| POST /hosting/oauth/start | 创建绑定用户的授权会话 |
| POST /hosting/oauth/complete | 完成授权，提交 session_id/code/state/name，可携带 settings |
| POST /hosting/two-fa-login | 创建绑定本人、目标池与重授权账号的 2FA 登录任务 |
| GET /hosting/two-fa-login/:id | 查询本人的登录状态，不返回凭证 |
| POST /hosting/two-fa-login/:id/complete | 验证登录结果并原子保存账号与 settings |
| DELETE /hosting/two-fa-login/:id | 取消并销毁本人的登录任务 |
| PUT /hosting/accounts/:id/settings | 保存本人账号的 OpenAI 调用配置 |
| GET /hosting/accounts/:id/usage | 查询本人托管账号的用量窗口，可传 force=true 主动刷新 |
| POST /hosting/accounts/:id/quota/refresh | 查询本人托管账号的积分和重置卡，缓存显示快照 |
| POST /hosting/accounts/:id/reset-quota | 消费一张重置卡并执行账号状态恢复 |
| POST /hosting/accounts/:id/pause | 暂停本人账号 |
| POST /hosting/accounts/:id/resume | 恢复本人账号 |
| DELETE /hosting/accounts/:id | 删除本人账号 |
| GET /admin/hosting/accounts | 分页查看全用户托管账号，可传 search/page/page_size |
| GET /admin/hosting/accounts/:id/usage | 后台查询托管账号的用量窗口 |
| POST /admin/hosting/accounts/:id/quota/refresh | 后台查询托管账号的积分和重置卡 |
| POST /admin/hosting/accounts/:id/reset-quota | 后台消费托管账号重置卡并恢复状态 |
| GET/PUT /admin/hosting/settings | 全局开关、席位与倍率 |
| GET/PUT /admin/hosting/users/:id | 用户席位与倍率覆盖 |

Key 创建/更新增加 `route_mode: "group" | "hosted"`、`hosting_pool_id`、`hosting_fallback_enabled`、`hosting_fallback_group_id`。托管 Key 不绑定普通 group_id。已有 Key 的 route_mode 迁移为 group。

创建接口省略 `settings` 仍兼容原客户端；提供时使用与账号编辑相同的字段白名单及校验，配置失败会回滚创建和席位占用。

首期没有席位购买、额外月费、跨平台兜底和订阅分组兜底。真实 OAuth、2FA 登录与真实订阅额度恢复仍需使用部署环境和真实账号做上线前联调。

## 用量归属与后台测试

迁移 `292_usage_hosting_pool_snapshot.sql` 为使用记录增加 `hosting_pool_id` 和 `hosting_pool_name`。每次请求（含 WebSocket 的新一轮）捕获托管池名称；进入兜底仍保留来源池。默认池 ID 为 0，历史未知为 NULL。旧记录只在 Key 和池均未发生后续修改时回填，无法确认的显示“托管池未记录”，避免用当前配置改写历史归属。

使用记录分别展示托管账号标准用量、用户余额实扣与本次倍率，金额保留 8 位小数。金额悬浮明细展示 Token 费用及用量金额 × 倍率 = 余额实扣；兜底记录显示来源池、实际分组和切换原因，CSV 同步导出归属信息。

管理员可在“托管账号 → 更多 → 智商测试”中使用原后台 IQTestModal 和管理员测试接口。用户端没有此入口，用户托管测试接口继续只允许固定连接诊断，不开放任意题目。
