# 托管账号与后台 OpenAI OAuth 对齐

托管使用用户自己的 Codex 订阅账号。界面复用后台账号组件，接口仍校验归属，不向用户开放通用管理接口。

| 项目 | 托管实现 |
| --- | --- |
| 状态 | 复用 AccountStatusIndicator：启用、停用、异常、RPM 暂停、429、529、临时不可调度、模型限流及恢复时间 |
| 临时不可调度 | 复用 TempUnschedStatusModal，查看触发时间、规则、原因并恢复状态 |
| 调度 | 复用 AccountSchedulingToggle；独立于账号状态和额度限制 |
| 用量 | 复用 OpenAIUsagePanel：5h／7d、点数、重置次数、手动查询及重置 |
| 统计 | 复用 AccountStatsModal，区分标准用量和历史实扣，保留 8 位小数和费用明细 |
| 基础配置 | 名称、备注、状态、托管池、并发、优先级、负载因子、过期时间、到期停用 |
| 模型 | 白名单／映射切换、别名、后台映射预设、上游模型同步、Compact 模式及映射 |
| OpenAI 调用 | 自动透传、WS 模式、SSE 加速、namespace 摊平、CLI 限制、App Server、图片工具策略、请求 ID 头、指纹模式、订阅档位 |
| 额度保护 | RPM、调度阈值、5h／7d 自动暂停、自动额度重置、临时不可调度规则 |
| 操作 | 编辑、删除、统计、重授权、查询用量、暂停／恢复、连接测试、刷新令牌、隐私设置、恢复状态 |

添加和编辑使用同一个配置表单。同步上游模型需要已保存账号。连接测试复用后台弹窗与测试服务，托管端仅发送固定短提示词，每账号每进程每分钟一次，避免测试入口变成任意请求的免计费通道。

用户侧重授权通过自己的 OAuth／2FA／导入流程完成；管理员可管理托管账号和用户策略，不代替用户重新登录。

不开放 BPS 网络策略、Prism、平台代理资源、公共分组绑定、平台采购／长上下文定价、跨用户门票借用与影子账号。托管费保持独立倍率。定时测试、IQ 测试和批量管理工具仍属于后台运维功能，未接入托管页面。

运行时响应采用字段白名单，嵌套模型限流只返回重置时间，错误详情脱敏。维护接口先校验归属与 OpenAI OAuth 主账号类型，GET 不执行修改操作。更新普通设置时不提交未修改的状态，避免覆盖并发产生的账号异常。
