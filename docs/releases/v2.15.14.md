# v2.15.14

Docker 会话一致性与内核连接复用修复

- 统一 OpenAI 调度与 Docker 转发的会话来源，按 API Key 隔离粘性绑定；临时借用其他账号不覆盖原会话绑定。
- 补齐缓存/会话身份以及 HTTP、WS 的 turn-state、turn-metadata 回传和续传，保留账号独立身份和缓存开关。
- 为主程序到常驻内核的 Unix socket 增加账号隔离连接复用；兼容内核 WebSocket SSE 事件封装，保持原并发、计费及状态机制。
- 修复顶层 thread_id 会话别名透传内核导致 400/502 的问题。
- 同步发布 amd64/arm64 Docker host tools、容器镜像和重新授权运行包，支持配套在线升级。

验证：本地大上下文、gpt-5.6-terra/xhigh，15 并发持续 5 分钟 99/99 成功；18 个 HTTP 边界请求全部成功，账号执行峰值 15、等待峰值 3；正常请求合计 120/120 成功。SSE/WS 取消后槽位释放，容器无重启/OOM。会话与调度定向测试及竞态回归通过。

边界：上游 TCP/TLS 跨请求复用仍取决于闭源 kin-codex-kernel，不将本地 UDS 复用等同于上游复用。WS 满载仍遵循现有 1013 busy 策略；首字长尾仍存在。本版本不重建账号/计费体系，不移植 VM 池调度。
